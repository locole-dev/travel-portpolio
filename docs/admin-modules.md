# Admin Modules

## Dashboard

- Overview cards for contacts, services, media items, and content last updated
- Quick links to edit profile, upload media, and manage services
- Recent content summary pulled from updated timestamps

## Profile Management

- Upload or replace avatar
- Edit full name
- Edit title
- Edit short intro
- Edit hero primary and secondary CTA labels and links
- Preview image selection from media library

## Contact Management

- Create, edit, delete contact methods
- Activate or deactivate contact methods
- Update platform, label, value, link, and icon
- Reorder records with numeric sort order

## Homestay Management

- Edit homestay section title and description
- Upload and assign gallery images
- Edit alt text per image
- Reorder images
- Remove gallery items

## Services Management

- Create, edit, delete service items
- Toggle active status
- Edit icon, CTA label, CTA link, and sort order

## Closing Section Management

- Edit thank-you title
- Edit closing message
- Edit CTA label and CTA link

## Media Management

- Upload new images
- Browse uploaded media in a grid
- Inspect file metadata
- Reuse existing asset in profile or homestay forms
- Delete only if asset is not currently assigned, or clearly warn the admin

## Settings And Auth

- Login screen
- Logout action
- Auth status check
- Basic account summary
- Future-safe role field, even if only one role is active in MVP
