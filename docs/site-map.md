# Site Map

## Public Routes

### `/`

Single-page marketing experience with the following sections:

1. Hero / Profile
2. Contact Methods
3. TwentyNine Homestay
4. Services and Transportation
5. Thank You / Final CTA

## Admin Routes

### `/admin/login`

- Admin sign-in page

### `/admin`

- Dashboard overview

### `/admin/profile`

- Edit profile hero content

### `/admin/contacts`

- Manage contact methods

### `/admin/homestay`

- Edit homestay intro and manage gallery

### `/admin/services`

- Manage service cards

### `/admin/closing`

- Edit final thank-you section

### `/admin/media`

- Upload, browse, filter, and reuse media assets

### `/admin/settings`

- Session status
- Account basics
- Security hints
